FIFO creation variants

Shell commands:
  mknod fifo_command p
  mkfifo fifo_command

Compare their Linux system calls with:
  strace -e trace=mknod,mknodat mknod fifo_command p
  strace -e trace=mknod,mknodat mkfifo fifo_command

The C examples use mknod() and mkfifo() respectively. Remove the FIFO between runs if the name already exists.

For creating a FIFO, mkfifo is the clearer command because it names the intended file type directly. The trace may show both utilities reaching mknodat or another node-creation syscall, depending on the Linux and coreutils versions.
